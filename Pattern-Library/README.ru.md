# Библиотека паттернов

На первом этапе эта библиотека намеренно остаётся пустой.

Наблюдение из референса становится повторно используемым паттерном только после сравнения нескольких сайтов или проверки в реальном проекте. Каждый будущий паттерн должен описывать решаемую задачу, исходные требования, структуру, адаптивное поведение, требования доступности, сложность, типичные ошибки и ссылки на источники.

Не переносите сюда фирменные иллюстрации, тексты или характерное визуальное выражение чужого бренда.
