# References

These are the sites AI should learn structure and style from. They are local-business scale, not SaaS homepages.

Do not copy branding. Take section order, content jobs, spacing, type, and how images are used.

Studio / offer sites stay in their own list at the bottom. Do not mix them into client generation.

## Client sites

About ten per category. For a real job, open several in the matching row — not all of them.

Several **local service** sites were built by Build 76. That is a useful quality floor. It is also one house style. Always mix in at least one site that is not theirs.

## How to use them

1. Pick the client category.
2. Open several sites from that row (five is a good pass; ten is the pool, not a requirement every time).
3. Structure pass: section jobs and order.
4. Style pass: type, space, image treatment.
5. If a real project is missing something this pool cannot teach, add one site — do not grow the list casually.
