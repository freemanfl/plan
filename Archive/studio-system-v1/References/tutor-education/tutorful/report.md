## Major responsive transformations

```text
DESKTOP                        TABLET                         MOBILE

Full navigation      →        Menu toggle          →        Menu toggle
Two-column hero      →        Two-column hero      →        Single-column hero
Five press logos     →        Five press logos     →        Horizontal overflow
Metrics + card       →        Metrics + card       →        Vertical stack
Two-column pathways →         Two columns          →        Stacked/scroll scene
Three reviews        →        Three reviews        →        Clipped carousel
Sticky 2-column      →        Sticky 2-column      →        Vertical sequence
Three benefits       →        Three benefits       →        One-column sequence
Five footer columns →         Five columns         →        Accordion rows
```

## Capture warning

Tutorful contains long scroll-driven or sticky scenes. A single full-page browser screenshot does not reproduce every animation state. Blank reserved regions and missing mobile media should be treated as dynamic capture limitations until the interactive behavior is inspected separately.
