# Система веб-студии

Этот репозиторий — операционная система студии: бизнес-решения, данные клиента, анализ референсов, правила дизайна, рекомендации по реализации и контроль качества.

Обсуждение может происходить в чате. Решения, спецификации и знания для повторного использования должны храниться здесь.

[English version](README.md)

## Единый производственный процесс

Данные клиента → бизнес-цель и конверсия → архитектура страницы → иерархия контента → компоновка с опорой на референсы → визуальная система → реализация → QA → сопровождение.

Каждый документ в репозитории поддерживает эту последовательность. Если два документа пересекаются, главным считается файл, указанный как источник истины в [производственной системе](Production-System/README.ru.md).

## Структура репозитория

- `Business/` — предложение, продажи, юридические вопросы, операции и стратегия.
- `Production-System/` — канонический процесс генерации сайта и его спецификации.
- `References/` — единый пакет материалов для каждого сайта-референса.
- `Pattern-Library/` — повторно используемые паттерны, прошедшие проверку.
- `Sandbox/` — эксперименты и временная работа; не источник истины.
- `Archive/` — устаревшие материалы, сохранённые для истории.

## Правила работы

1. Обновляйте канонический документ, а не создавайте ещё одно объяснение той же идеи.
2. Каждый сайт анализируйте в едином формате референса.
3. Отделяйте наблюдения от рекомендаций и повторно используемых паттернов.
4. Переносите паттерн в библиотеку только после сравнения нескольких референсов или проверки в реальном проекте.
5. Заменённый материал отправляйте в архив; не оставляйте две активные версии.
6. Английские имена файлов и ключи схем являются каноническими. Русские пояснения используют суффикс `.ru.md`.
